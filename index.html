Choose a file, describe it with structured details, check the automatic preview, then submit it for publication. An administrator reviews new submissions before they appear in the public library. As the administrator, your uploads are published to the library immediately.

Upload approved teaching resources only. Do not upload student names, grades, medical information, private staff records, copyrighted files without permission, or anything that should not live in a public repository.

GitHub Auto-Publish

Connect a GitHub token and approving a submission publishes it automatically: the file is committed to the apps folder and its metadata merged into library.json. Without a token, the manual copy/paste flow keeps working.

Status

The token itself only ever lives in this tab's session storage and is only ever sent to api.github.com. Closing the tab or signing out forgets it. Saving it to GitHub Cloud (below) publishes encrypted bytes — never the token in the clear.

Create it on GitHub with access to only this repository and the single permission Contents: Read and write. Nothing else is needed.
